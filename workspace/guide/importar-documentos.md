# Importar documentos

A importação cria uma fonte original e um artigo sem revisão para cada arquivo Markdown próprio. Nenhum artigo existente é sobrescrito.

## Preparar os arquivos

- Selecione de 1 a 32 arquivos .md, com total até 128 KiB em UTF-8.
- Use nomes diferentes que gerem endereços diferentes: acentos e espaços são simplificados no endereço do artigo.
- Inclua no mesmo lote os documentos ligados entre si.
- O título inicial é separado do corpo do artigo para aparecer uma única vez no leitor; o original não muda.
- Links para arquivos do lote são adaptados para os artigos HTML; o texto da fonte original permanece intacto.
- Imagens, metadados front matter e links por referência precisam de preparação separada.
- Links locais sem destino no lote bloqueiam a importação. Referências HTTPS são mantidas, mas não são visitadas ou verificadas pelo aplicativo.

## Conferir antes de salvar

1. Em Artigos, clique em Importar Markdown.
2. Selecione os arquivos e informe os limites públicos comuns.
3. Declare que o conteúdo é próprio.
4. Clique em Conferir lote.
5. Expanda cada documento e compare o original com o rascunho proposto.
6. Se não houver conflitos, confirme e clique em Importar rascunhos.

A prévia não salva dados. O lote é salvo inteiro ou recusado inteiro. Se o projeto mudar depois da prévia, será preciso conferir novamente. Cancelar encerra a preparação sem importar.

## Depois da entrada

Os artigos entram como A revisar. Ajuste os limites específicos de cada um, confira a formatação e registre uma revisão antes de publicar. Não interprete a importação como verificação da verdade do conteúdo.
