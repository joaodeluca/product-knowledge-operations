PARA QUEM MANTÉM A AJUDA DO PRÓPRIO SOFTWARE

O trabalho continua depois de escrever.

01 / ORIGEM

Traga o que já existe

Importe até 32 arquivos Markdown próprios por lote. Confira títulos e prévias antes de confirmar. Originais ficam guardados no histórico privado.

02 / CONFERÊNCIA

Saiba o que foi revisado

Leia cada artigo na fila de revisão. Uma edição vence a revisão daquela versão. A próxima publicação exige nova conferência.

03 / ENTREGA

Entregue um leitor utilizável

Exporte a central HTML com busca local. Fontes e notas internas ficam de fora. O leitor funciona sem o aplicativo; a hospedagem fica sob seu controle.

04 / CONTINUIDADE

Atualize e recupere

Edite com prévia e consulte as versões anteriores. Preserve publicações e faça backup privado JSON para recuperar em novos projetos.

SEU PRIMEIRO PROJETO

Abra e comece a escrever.

Usar o Workspace web →

Importe Markdown ou texto, edite, revise e baixe uma central HTML com busca. Entre na conta habilitada para salvar no servidor e abrir seus projetos em outros dispositivos. Projetos locais continuam separados: use “Copiar projetos locais” para enviá-los com sua confirmação. Faça também backup privado JSON; ele não é compatível com o ZIP da versão Python.

Prefere a versão Python?

Não é necessário instalar bibliotecas Python. O aplicativo precisa ficar aberto enquanto você edita.

Notas da versão e checksum

  1. EDIÇÃO PYTHON 0.5 · OPCIONAL

    Baixe e extraia o ZIP

    Abra um terminal na pasta knowledge-workspace extraída. Confirme seu Python com python3 --version.

  2. Inicie o workspace

    python3 serve.py --store "$HOME/KnowledgeWorkspace/meu-projeto" --open

    Na primeira execução, escolha uma pasta de dados vazia. A interface abre no navegador e os dados ficam no computador. Ctrl+C encerra o servidor; execute o mesmo comando para continuar depois.

  3. Crie a central e importe seus documentos

    Defina nome, contexto e limites. Na Visão geral, siga Importar documentos → Revisar próximo artigo → Gerar central → Baixar central ZIP. Cada revisão exige sua confirmação.

  4. Abra o leitor e guarde o trabalho

    Confira a central exportada antes de compartilhá-la. Use Backup privado para guardar também fontes, rascunhos e histórico. Esse backup contém informações internas e não deve ser compartilhado como central pública.

O QUE ESTA PRÉVIA FAZ

Um operador.

ANTES DE USAR

Confira a adequação ao seu trabalho

  • Não gera texto por IA nem executa os procedimentos para validar sua verdade.
  • Não tem edição colaborativa simultânea, contas de equipe, sincronização offline ou hospedagem automática da central exportada.
  • A edição web aceita até 32 arquivos UTF-8 e 512 KiB por lote; 128 KiB por arquivo. Imagens e anexos não são carregados; HTML aparece como texto.
  • A conta privada exige conexão e login em cada sessão. O plano gratuito pode pausar por inatividade. Backups não têm criptografia; não inclua credenciais.
  • A revisão do operador não é assinatura de identidade verificada ou aceite de cliente.
