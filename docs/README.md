# Ajuda independente para trabalhar com seus arquivos

Escolha o procedimento pelo resultado que precisa obter. Os guias podem ser lidos diretamente aqui, sem servidor local. São materiais próprios e gratuitos, sem vínculo com os fornecedores.

| Necessidade | Procedimento e alcance |
| --- | --- |
| Guardar um desenho editável e continuar em outra sessão | [Excalidraw: salvar e recuperar](excalidraw/SAVE-RESTORE.md). Cena própria fictícia de 05/10, imagens e arquivo editável para baixar. O ensaio anterior de 04/10 continua parcial. |
| Transferir e conferir um projeto com seus dados | [OpenRefine: transferir e recuperar](openrefine/TRANSFER.md). Fonte fictícia, exportações e arquivo de projeto. Transformação e recuperação observadas pela API; CSV após desfazer perdeu espaços externos e o aceite integral original FAILED permanece. |
| Escolher o modo correto para validar uma configuração | [Renovate: validar configuração](renovate/VALIDATION.md). Diferença entre configuração global e de repositório, migração e saída sem arquivo. RE2 não carregou: regex não certificada; onboarding não executado. |

[Quatro arquivos originais da cena Excalidraw](https://github.com/joaodeluca/product-knowledge-operations/releases/tag/help-2026-10-05) estão em uma publicação de anexos, marcada como pré-lançamento. Não é uma versão do Excalidraw nem uma distribuição de software dos fornecedores.

Os resultados são delimitados às amostras descritas. Não comprovam instalação de um participante, trabalho aceito por cliente, manutenção contratada, economia ou venda. [Apresentação e condições da avaliação pública](../README.md).
